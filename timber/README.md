# Timber: from design to fabrication

From lines to timber beams, joints and fabrication files, using [COMPAS Timber](https://gramaziokohler.github.io/compas_timber/). Dimensions are in millimeters.

## Examples

* [01 · From a line to a beam](./01_line_to_beam.gh)
* [02 · Joints (L, T, X)](./02_joints.gh)
* [03 · Design to fabrication](./03_design_to_fabrication.gh): a stud wall, its cutting list and a BTLx file

## Exercise

Design a timber pergola, starting from [`exercise/pergola.gh`](./exercise/pergola.gh).

To export the BTLx: right-click `btlx_file` > *Select one existing file* (create an empty `.btlx` first), then set `export_btlx` to `True`.
